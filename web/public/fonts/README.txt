Replacing NeoXiHei with the original IPA font:
1. Obtain the original IPAexGothic font from its official distributor: https://moji.or.jp/ipafont/ipaexgothic/ . Extract ipaexg.ttf from the downloaded package.
2. Copy ipaexg.ttf into web/public/fonts/ alongside the bundled licenses.
3. In web/src/styles.css, find the @font-face rule for the application alias NeoXiHei. Replace src: url('/fonts/LXGWNeoXiHei.ttf') format('truetype') with src: url('/fonts/ipaexg.ttf') format('truetype'). The CSS family alias can remain NeoXiHei so existing UI declarations use the replacement font.
4. Rebuild the web app. Keep the original IPA license supplied with the font. Chinese glyphs absent from IPAexGothic use the declared system fallback.
The original full license notices are included beside the binaries.
