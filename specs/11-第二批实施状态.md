# 第二批实施状态

日期：2026-10-12。范围为 P2 账单与订阅，以及 P1 会话、通知与已审第四版界面的补做。开发前固定 [接口契约](contracts/second-batch-api.md)，与 [账单订阅 SPEC](features/账单与订阅SPEC.md)、[会话界面 SPEC](features/会话通知与界面SPEC.md) 对齐。

## 已实现

| 包 | 实现与用户入口 | 边界 |
|---|---|---|
| M15 账单 | CSV 模板、导入、行错误、重复去重、中文商户别名、来源与规则依据 | 独立账单记录不修改银行资金；CSV 最多 2MB |
| M16 分类报告 | 日期筛选、收入、退款、净支出、分类、聊天汇总 | 整数分确定性计算；转账和期初余额不计消费；覆盖期明确 |
| M17 异常提示 | 单次大额、同日重复、商户金额偏离的规则提示 | 复核线索，未训练欺诈模型，未用 Kaggle 标签作生产判定 |
| M18 周期检测 | 周/月/季/年规则、漏月、变价、别名、房租非订阅 | 置信度是规则分数；近邻扣款合并为周期事件，全部证据 ID 保留 |
| M19 订阅部分 | 三份模拟合同、停止代扣/取消合同预览、确认与拒绝、状态核验 | 轻云存储不支持取消合同；候选不能直接执行；卡片部分未实现 |
| 会话与通知 | 主会话、临时事项、新建/改名/切换、历史恢复、未读、操作回执与续费提醒 | 固定单用户；提醒在启动/读取通知时生成，未实现后台定时扣款 |
| 前端 | 可收起会话栏、灰白配色、真实字体、按动作自动展开的可关闭确认抽屉、手机适配 | 第四版图稿为基线；实现展示服务端数据与实际状态 |

DeepSeek 官方 `deepseek-flash` 经既有适配器调用，LangGraph 负责读事实/创建预览工具循环。模型没有批准工具。账单、订阅与银行通过冻结接口组合，业务表分别持久化；对同一会话的聊天与按钮预览串行处理，跨会话动作独立。

知识库仍为三个自写模拟资料文档，版本升至 0.2；Markdown 标题分块、中文分词与 BM25 检索，引用与历史一起恢复。向量检索、混合召回、重排和研究创新对照尚未实施。

## 本轮验证

- 后端 `pytest -q`：82 项通过，无跳过。包含专用 PostgreSQL 测试库上的转账与订阅并发检查；应用库没有被测试重置。设置 `BANK_TEST_DATABASE_URL` 与 `SUBSCRIPTIONS_TEST_DATABASE_URL`，只允许 `127.0.0.1:55432/concierge_test`。
- Ruff 与自写内容的 Git 空白检查通过；字体许可保留上游原文。前端 TypeScript / Vite 构建通过；接口与 SSE 测试 9 项通过。
- 离线 API 检查：日期错误、重复导入、分类净额、跨会话隔离、错会话确认拒绝、同会话预览串行、知识来源恢复、旧历史迁移、回执去重与提交后故障恢复。
- CUA 浏览器：桌面 1488×1058、手机 390×844；会话新建改名、刷新、收起、切换、确认面板关闭和重开、CSV 正确/错误/重复行、退款与日期筛选、订阅两种预览与拒绝。修复了日期输入事件、手机长标题和正文宽度。
- 真实 DeepSeek：聊天汇总十月账单；创建并确认 ¥1.23 模拟转账；创建并确认停止轻云存储代扣，核验合同仍有效；知识问答与来源展开。不是用离线模型替代这部分验收。
- 本地正式入口 `http://127.0.0.1:8000/` 使用构建文件与字体静态路由。服务重启后，转账与订阅操作各恢复一个通知，模拟日常账户为 9,050,444 分，流水 14 笔。金额是本轮本地快照，不是初始化常量。

浏览器检查保留了四条独立合成导入账单和验收会话；它们不进 Git，也不改银行余额。字体随包附许可与原字体替换说明，文楷 WOFF2 分块按需加载。
