# 任务连续性、知识衔接与个性化：第一轮

2026-10-24。用户授权按创新分析开工。本轮先实现三个可独立验收的后端增量，并提供新增交互样稿；新增前端须先获样稿认可，之后由 medium 实现。既有四入口、侧栏、字体方向和聊天布局不改。

本轮最新授权：用户明确说“图片你自行审核没问题就行，继续做吧”。因此本轮样稿由主任务自行审核，合格后直接交medium实现，无需再次等待用户选稿。四入口与整体布局保持的约束继续生效。

## 范围与完成边界

1. **可局部改口的生活安排**：从已有未确认安排预览读取当前参数，修改标题、对象、预算、账户、执行时间或服务数量/移除服务。其余字段保留，重新按目录报价，返回字段变化摘要。有效修改替代旧确认单；非法修改不破坏原预览。已执行或已确认任务不能通过修改草稿重新执行。此轮是跨场景连续计划的首个切片，不宣称任意六场景任务图已实现。
2. **上下文知识检索与办理衔接**：保留现有 BM25 baseline；增加基于当前问题、最近用户消息及当前事项的有界上下文查询扩展，覆盖六场景及新管理能力。知识回答不清空当前预览；新话题不得被上一话题污染。不新增 embedding 供应商，不让模型自行计算账务或把检索资料当实时余额。
3. **明确授权的个人分类规则**：单笔改分类仍仅影响单笔；用户明确要求“以后这个商户都归为……”才创建个人规则。按规范化商户精确匹配，可限制交易类型和备注条件，支持查看、更改、删除。显式单笔标注优先于个人规则，个人规则优先于默认关键词。默认仅影响生效日及之后的记录；不静默重写历史原始流水或修改余额。不把它称作模型训练或通用长期记忆。

## 接口分工

- 工作流服务新增 `revise_action_plan(plan_id, conversation_id, changes)`；返回标准 workflow plan（兼容现有确认UI），附 `revision` 信息：来源计划、变化列表。变化由服务端比较得到，不能接受模型伪造的旧值。同一服务内完成验证、创建及旧预览失效，避免旧页重复修改覆盖新预览。
- Agent 新增只读当前预览工具及安排修改工具，复用原确认入口，不开放模型批准工具。
- 知识服务新增兼容接口 `search_contextual(query, history=None, limit=4)`；返回与 `search` 相同的资料结构，必要时附扩展说明。保留原 `search` 用于对照；新策略可切换。
- 个人规则由账单服务管理；API 提供列表、创建、修改、删除，使用版本冲突检查。Agent 允许查看规则；明确长期意图才保存规则，普通账单问题不触发写入。具体工具字段与服务实现共同核对后接入。
- 根任务负责 main.py、agent.py 接入与跨模块验收；各子任务不得同时编辑公共入口。

## 视觉方案（待审，未实施）

在当前灰绿桌面框架内提供三份独立样稿，展示同一生活安排的不同层次组织方式。左侧四入口及置顶/最近保留，主区维持14.5px阅读尺度和16px标题，只使用一个可关闭右面板。任务信息分为摘要、可编辑内容、真实状态/变化和一个主动作。不展示虚构成功，不新增导航，不生成装饰卡片墙。金额对齐、对比度、字体角色、状态过渡纳入后续实现规范。

样稿用2026-10-24为时间锚点，金额明确为设计示例。图片区分概念与已实现功能；没有获批前不修改生产CSS/TSX。沿用用户此前要求的 ChatGPT 创建图像渠道与可用高推理模式；渠道不可用如实说明，不静默替换。

## 验收

| 能力 | 必须检查 |
|---|---|
| 改口 | 花+蛋糕→仅保留花；保留对象/账户/时间；改预算；无效低预算/未知商品保留原预览；旧计划不能再次确认；已完成不能改成草稿；读知识不撤预览；重启后仍能继续 |
| RAG | 六场景每类多个说法；“那手续费呢/多久到”继承相关事项；明确换话题不污染；无资料不编造；与baseline在独立表达上比较命中、回答及办理衔接 |
| 个性化 | 单笔更正不泛化；长期规则作用于新记录；备注条件不匹配不作用；显式标注覆盖规则；更新/删除/重启一致；金额/余额不变 |
| Agent | 实际工具调用接入；确定性模拟模型测试与少量真实DS对话分别报告；没有实际验证的能力不计完成 |

实验记录任务、固定基线、结果和失败即可，不做hash检验、dry-run或大型证据包。通过不等于论文原创或真实银行验证。API故障与实验未完成如实报告。测试数据使用独立本地库，保留用户现有演示数据。不自动提交或推送GitHub。

## 来源与研究边界

- [Generative Interfaces](https://arxiv.org/abs/2508.19227)：参考任务适配界面；本轮只做设计，不宣称实现全文系统。
- [Agent Workflow Memory](https://arxiv.org/abs/2409.07429)：参考流程连续性；本轮不训练工作流记忆。
- [CRAG](https://arxiv.org/abs/2401.15884)：参考检索纠正；此轮上下文扩展不是完整CRAG复现。
- [FinPerMA](https://arxiv.org/abs/2608.04095)：参考偏好变化评测；分类规则属于有限的显式个性化。
