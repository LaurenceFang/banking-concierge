# DeepSeek 官方模型配置

主模型固定为 DeepSeek 官方 V4.1 Flash。首版只围绕该模型实现接口、知识问答和银行任务流程。

## 配置

| 项 | 设置 |
|---|---|
| 提供商 | DeepSeek 官方 |
| 地址 | https://api.deepseek.com |
| Chat 接口 | /chat/completions |
| API 模型 ID | `deepseek-flash` |
| 官方对应版本 | DeepSeek V4.1 Flash |
| 凭据 | `DEEPSEEK_API_KEY` 或本机用户范围加密凭据 |
| 模型网关与本地推理 | 首版不使用 |

官方说明使用 `deepseek-flash`，旧别名不作为项目默认值。[官方模型说明](https://api-docs.deepseek.com/quick_start/pricing/)

## 调用方式与体验

简单参数提取和知识问答优先非思考模式，复杂多步骤规划按实际失败情况开启思考。以流式输出、复用已知上下文和有限重试改善等待与连续办理。

JSON 输出设置 `response_format={"type":"json_object"}`，提示词提供结构样例；服务端检查字段和业务含义。空内容或截断按错误处理，不进入业务提交。[JSON 文档](https://api-docs.deepseek.com/guides/json_mode/)

思考模式带 tools 的后续请求完整保留 `reasoning_content`；普通界面和日志不展示内部推理全文。官方说明缺失该上下文可能造成 400 错误。[思考与工具文档](https://api-docs.deepseek.com/guides/thinking_mode/)

模型超时、限流与错误转换为清晰用户状态。业务操作重试与模型重试分开；只在执行结果确实成功时报告完成。

## 密钥与费用

密钥不进入文档、源码、普通日志和源码包，只发送至用户指定的 DS 官方 HTTPS 接口。调用记录保留 token 用量和异常。仍有超时、有限重试和工具循环上限，避免程序卡住；不自动购买额度或开通其他服务。

## 最小连通验证

2026-10-10 已完成 DS 官方接口最小验证：模型列表、JSON 金额参数提取、合成余额工具请求及结果回传均通过。三次 Chat 请求使用 `deepseek-flash`，合计 639 tokens；另有一次模型列表请求。测试采用非思考模式与合成只读工具，没有银行写入操作。

凭据通过环境变量或本机凭据加载，不包含在此仓库。思考模式、多轮复杂任务、流式体验、完整应用和 RAG 用户路径仍需后续检查。
