## 复查命令

默认 `uv run pytest -q` 使用临时 SQLite 并跳过 PostgreSQL 专项。检查 PostgreSQL 时，先启动 `compose.yaml` 的数据库，再创建专用测试库：

```powershell
docker exec banking-concierge-db createdb -U concierge concierge_test
$env:BANK_TEST_DATABASE_URL = 'postgresql+psycopg://concierge:local-demo-only@127.0.0.1:55432/concierge_test'
uv run pytest -q
uv run ruff check backend
```

`createdb` 只在首次需要，测试库已存在时不重复创建。测试仅接受上述本地专用测试库地址并重建其银行表，不重置应用使用的 `concierge` 库。
