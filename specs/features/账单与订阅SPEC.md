# 账单与订阅规格

关联 SC-02、SC-05，模块 M15–M19 和通用安全执行模块。共享归一化流水，分类、周期检测和操作分别提供证据。

## 数据口径

导入保留来源行、日期、时区、商户原文、规范化商户、金额、币种、账户与交易标识。明确扣款、退款和转账口径。重复导入按业务标识或规范化内容去重；发生冲突时提示，不悄悄覆盖。

月报与年报由确定性计算产生。数据覆盖不完整时注明区间，不能把几个月流水推算为实测全年。异常信号不等于已证明欺诈。

## 需求与验收

| 编号 | 行为 | 验收重点 |
|---|---|---|
| BILL-001 | 归一化与去重 | 重复文件不重复计账；金额和日期歧义明确处理 |
| BILL-002 | 消费分类 | 原商户、类别、规则或模型版本和置信度可查询 |
| BILL-003 | 汇总与报告 | 分类总和与定义的账单总额一致，退款和转账口径一致 |
| BILL-004 | 异常识别 | 指出异常原因并保留误报，不能当作自动授权结论 |
| BILL-005 | 数据与注入隔离 | 上传备注中的指令不能触发取消或转账 |
| SUB-001 | 周期候选 | 周、月、季度、年模式和置信度；未确认候选不冒充合同 |
| SUB-002 | 不规则情况 | 漏月、变价、商户混写、月长变化和正常周期消费单独评测 |
| SUB-003 | 续费提醒 | 有效授权下在约定窗口提醒，重启不重复提醒 |
| SUB-004 | 商户取消 | 确认后调用支持取消的模拟商户，核验商户订阅状态 |
| SUB-005 | 代扣撤销 | 仅撤销扣款授权时明确说明，不能宣称商户服务已取消 |
| SUB-006 | 不支持与失败 | 不支持取消或工具超时给出实际状态和下一步，无虚假成功 |

## 基线与创新

基线采用 SubTrackr 风格清洗、关键词分类、周期窗口和时间一致性规则。改进实验针对中文商户别名、缺失周期与价格变化，并与基线使用同一锁定测试集。

合成数据明确标注真实订阅、周期性非订阅和一次性交易；不能只埋简单月扣数据再声称能处理真实订阅。取消的权限、确认和结果验证与检测分开测试。
