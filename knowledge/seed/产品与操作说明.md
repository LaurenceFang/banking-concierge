# 模拟产品与操作说明

本资料适用于银小二演示环境，不代表微众银行真实产品或商户服务。只有已接入业务工具返回的状态才是业务事实；知识资料和模型回答不能替代工具结果。

## 当前可用范围

当前实现支持演示账户与交易查询、模拟转账预览和确认、账单统计与 CSV 导入，以及固定模拟订阅的查询和确认操作。账单模块读取银行交易时只读；导入与演示流水存放在独立账本，不写银行交易、不改变账户余额。报告按整数人民币分确定性计算，区分消费、退款、收入、转账和期初余额，并标明实际数据覆盖范围。

在启用生活安排能力的实例中，当前模拟服务目录可组成多步骤安排。预览阶段不下单、不预留资金；用户确认后才预留当次实际报价金额（不是预算上限）并按顺序执行。若某步骤失败，后续步骤停止，可退款且未履约的模拟订单会自动进入补偿退款；不支持取消或已履约的订单会保留为净支出，退款失败会进入退款待处理状态。资金和商户订单仅属于演示账本。未启用该功能的实例不提供生活安排工具。

订阅页面分开显示模拟订阅与账单推测候选。候选根据流水周期、别名、缺失周期和金额变化估算，不代表已建立或已授权的订阅关系，不可用于执行取消或停扣。当前三份预置模拟订阅为星云视频、云舟音乐和轻云存储；只有视频和音乐支持模拟商户取消。轻云存储不支持商户取消，只能通过独立预览及确认关闭代扣授权。关闭代扣后该订阅仍然有效，不能宣称服务已取消。

## 账单整理与订阅管理

账单支持按日期、商户或备注、分类和来源筛选。银行流水和演示记录可以整理分类、标签和备注，但原始金额、日期、商户和收支方向保持只读；导入流水可按页面提供的字段更正，手工记录可新增、编辑和移除。导入与手工记录只改变独立账本及其统计，不改变银行账户余额。

用户明确要求记住商户分类时，可通过聊天或账单分类规则后端 API 创建、查看、修改和删除个人分类规则；目前没有独立的规则管理页面。规则按规范化商户精确匹配，可选限定交易类型及备注包含词，并设置生效日期。规则只适用于创建后进入账本、交易日期达到生效日的银行投影和导入记录。它不回写现存记录，也不改金额或余额。CSV 明确给出的分类、手工录入分类和单笔显式分类标注优先；删除规则后由规则推导的分类回到基础分类，单笔标注继续保留。

导入批次记录本次新增、重复、错误、单条移除和剩余数量。批次撤销仅删除该批仍存在的新增记录；重复记录没有归属到本次批次，不能因撤销而删除。单条移除导入记录会标记相应批次关系，后续撤销不会影响其他记录。

个人订阅记录用于个人账本中的周期支出和提醒，支持新增、修改、移除；移除会结束后续提醒，但不会联系商户或取消真实服务。候选确认可关联创建个人记录；忽略、不是订阅、恢复处理只改变候选反馈，不产生已授权的商户服务。

## 尚未接入的操作

当前没有真实商户或支付宝连接，没有真实鲜花订购、代付、配送或对外自动扣款。启用生活安排能力时，鲜花、蛋糕等目录条目只代表模拟商户的演示订单；模拟退款也不代表真实商户已退款。模拟卡片与理财页面已开放；状态和确认单由对应业务工具返回，不能编造未展示的按钮或成功回执。卡片支持正常、冻结、挂失和关闭状态及限额；理财支持三个自写产品、完整风险测评、持仓和业务日T+1订单。真实业务需要对应正式渠道，不能把模拟规则冒充真实政策。

## 操作预览

只有当前入口已开放的动作才能生成预览。预览说明具体对象、金额或状态变化、操作范围和有效期；模型不得自动批准。用户确认的是当前预览，改变对象或操作后应重新预览。卡片和理财沿用共享确认面板，关闭后可从原会话重新打开。

订阅取消仅适用于支持取消的模拟条目；停止代扣只影响模拟银行侧授权，不代表商户服务取消。两种结果需要按工具返回的订阅状态和代扣状态分别展示。

## 结果查看

已完成表示模拟业务工具返回实际完成状态；处理中表示尚未结束；被拒绝或不支持时应说明当前状态和可用下一步。状态未知时先查询原操作，避免重复提交。知识检索命中不代表操作已提交或成功。

理财“已受理”只表示订单和必要的现金扣款或份额预占完成；申购待结算不计持仓，赎回待结算不算到账。实际结算后才更新对应持仓或银行现金，并发送结算回执。本金属于资产转移，不计账单消费或收入；独立手续费计金融服务消费。
