# 模拟银行知识库

此目录保存银小二演示环境的项目自写资料，不代表微众银行真实产品、政策或已接入服务。知识库保持三个 Markdown 文档及现有 manifest schema；当前内容版本为 0.4。

- `manifest.json`：文档 ID、来源、版本、分类和可见范围。
- `seed/业务FAQ.md`：转账、账单、订阅、卡片、理财结算及尚未实现的能力说明。
- `seed/产品与操作说明.md`：当前已支持的模拟能力、预览确认和服务边界。
- `seed/故障帮助.md`：账单导入、订阅操作和其他失败的恢复说明。

`backend/app/knowledge` 按 Markdown 标题分块，使用中文分词与 BM25 检索，并返回文档版本、标题和片段。修改后重启应用以重新加载。知识资料解释当前可用能力；实时账户、账单、模拟订阅和操作状态仍由业务工具读取。不得把推测候选写成已授权订阅，也不得把模拟操作描述成真实商户服务结果。

`KnowledgeService.search` 是无上下文 BM25 基线。`search_contextual(query, history=None, limit=4)` 只会在简短续问中引用最近相关的用户消息；如果新问题明确转向不同业务领域，则只按本轮问题检索。该方法没有模型或外部 API 调用，输出资料行结构与 `search` 相同。
