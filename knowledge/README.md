# 模拟银行知识库初始资料

此目录包含项目自写的模拟银行知识资料，不是微众银行真实产品、承诺或服务政策。已用于首轮 RAG 检索和问答。

- `manifest.json`：文档 ID、来源、版本、分类和可见范围。
- `seed/业务FAQ.md`：六场景常见问题与下一步操作。
- `seed/产品与操作说明.md`：产品说明来源、预览、确认、取消和状态解释。
- `seed/故障帮助.md`：用户可理解的失败原因和恢复路径。

`backend/app/knowledge` 按 Markdown 标题分块，使用中文分词与 BM25 检索，并输出文档版本、标题和片段。修改资料后重启应用以重新加载。业务实现时同步核对文档与实际能力，不能用知识文档模拟已经成功的业务。
