# 银小二使用指南

启动后打开 http://127.0.0.1:8000/。当前页面绑定虚构用户林小满，所有余额、联系人和交易均为演示数据。

## 最短体验路径

1. 点击“查询余额”，查看两个账户及合计。右侧账户概览显示同一份余额。
2. 输入“给陈晨转500元”。银小二查找收款人并生成转账预览，此时没有扣款。
3. 核对金额、收款人及付款账户，点击“确认转账”。成功后出现回执，账户余额和最近交易更新；点击“取消”则不扣款。
4. 输入“停止代扣就等于取消会员吗”。答复下方点击“查看依据”，展开检索到的知识片段。

## 页面上的按钮

- **对话**：输入需求，查看答复和转账卡片。Enter 发送，Shift+Enter 换行。
- **账户**：查看账户余额，手机端也可从这里打开账户概览。
- **交易**：查看最近流水。当前只展示最近记录，尚未提供账单统计和订阅检测。
- **查询余额 / 最近交易 / 转账规则**：快速发送示例问题。
- **刷新**：重新读取服务器数据。

刷新浏览器页面会开始新的对话；当前界面尚未提供历史对话恢复。已经完成的交易和余额继续保留。

## 预览与状态

- **等待确认**：核对预览后才能执行转账。模型只能创建预览，不能代替你按确认。
- **已完成**：有实际模拟交易回执，余额和流水已更新。
- **已取消 / 已失效**：未执行。发送新问题或修改需求后，上一张待确认卡片失效；请使用新生成的卡片。
- **失败**：查看页面提示，修正金额、收款人或连接后再试。请求中断时不会自动重发。

“给张伟转100元”会返回两位同名收款人，请根据银行、尾号选择。“给陈晨转100万元”会提示余额不足。

理财、卡片、订阅目前可询问概念与操作说明，尚不能执行申购、挂失、取消订阅等业务。停止银行代扣与取消商户会员属于不同动作。

## 关闭和重新打开

启动终端按 Ctrl+C 停止应用，再次运行启动脚本即可。PostgreSQL 数据不会在重启时重置；数据库停止可运行 `docker compose stop postgres`，不要删除持久化卷。开发模式的前端和后端分别在各自终端停止。
